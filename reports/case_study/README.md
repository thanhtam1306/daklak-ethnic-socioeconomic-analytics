# PROJECT PORTFOLIO CASE STUDY
Thư mục chứa tài liệu báo cáo Case Study hoàn chỉnh phục vụ hồ sơ năng lực (Portfolio / CV / Interview Prep):

- `daklak_socioeconomic_case_study.md`: Bản trình bày đầy đủ theo cấu trúc:
  1. **Executive Summary**: Tóm tắt bối cảnh và kết quả quan trọng nhất.
  2. **Business Problem & Objectives**: Bài toán chính sách cần giải quyết.
  3. **Data Architecture & Wrangling**: Thách thức dữ liệu thực tế và cách giải quyết (Merged cells, Tidy Data, Star Schema).
  4. **Top 5 Actionable Insights**: 5 phát hiện cốt lõi với số liệu định lượng và nguyên nhân gốc rễ.
  5. **Policy Recommendations**: Đề xuất phân bổ ngân sách và can thiệp trọng điểm.
  6. **Technical Takeaways**: Bài học kinh nghiệm và kiến trúc kỹ thuật.
