# SQL ANALYTICS QUERIES (DUCKDB)
Thư mục chứa các tệp truy vấn SQL khai phá insight kinh tế - xã hội nâng cao:

- `01_demographic_structure.sql`: Phân tích quy mô, tháp tuổi, tỷ trọng dân tộc và tốc độ tăng tự nhiên.
- `02_education_human_capital.sql`: Phân tích khoảng cách học vấn, tỷ lệ biết chữ, bất bình đẳng giới tính trong tiếp cận giáo dục.
- `03_labor_employment_transition.sql`: Phân tích chuyển dịch cơ cấu việc làm nông nghiệp vs phi nông nghiệp.
- `04_multidimensional_poverty_index.sql`: Xác định top các xã và nhóm dân tộc thuộc "vùng trũng nghèo đa chiều" (nhà tạm + thiếu nước sạch + thiếu hố xí hợp vệ sinh).
- `05_infrastructure_impact.sql`: Đánh giá tác động của đường giao thông và khoảng cách địa lý tới mức sống hộ gia đình.
